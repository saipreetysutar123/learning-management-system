# Learning Management System

A web-based Learning Management System (LMS) that helps students and instructors manage courses, assignments, and learning materials efficiently.

## ✨ Features

* User Authentication and Authorization
* Student and Instructor Dashboards
* Course Creation and Enrollment
* Assignment Upload and Submission
* View Course Materials
* Track Student Progress
* Responsive User Interface

## 🛠 Tech Stack

**Frontend**

* React.js
* HTML
* Tailwind CSS
* JavaScript

**Backend**

* Node.js
* Express

**Database**

* MongoDB

**Tools**

* Git
* GitHub
* Postman

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js and npm
* MongoDB
* Git

### Installation

1. Clone the repository

```bash
git clone https://github.com/saipreetysutar123/learning-management-system.git
```

2. Navigate to the project directory

```bash
cd learning-management-system
```

3. Configure the database in the backend .env file.

4. Start the backend server.

5. Start the frontend application.

6. Open the application in your browser.
